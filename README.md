# 文途行迹 · 中国现代作家城市足迹交互地图

> 一张图读懂中国现代作家的城市足迹 —— 人文 AI 创新应用参赛作品

## 在线访问

本站已通过 GitHub Pages 部署，直接访问：
**https://lesu7436-ux.github.io/Literary-Trails/**

## 功能

- **总览地图**：中国地图按"作家到访热度"省份着色，悬停查看城市与作家明细，海外城市锚点
- **作者详情**：15 位现代文学大家的生平、人生时间轴、城市足迹路线、代表作、名句
- **对比分析**：多选 2–5 位作家，路线叠加地图 + 并行时间轴 + 共同城市 + 交集关系
- **作品库**：315 部作品按作家 / 年代 / 城市筛选检索
- **开屏**：仅首次访问显示的书法开屏，平滑过渡进入主站

## 本仓库说明

本仓库为**生产构建产物**（纯静态站点，`base:'./'` 相对路径 + hash 路由，可离线运行）。
完整工程源码（Vue 3 + Vite + TypeScript + ECharts）与数据校验脚本见参赛提交包内的 `源码/` 目录。

## 本地运行源码

```bash
npm install
npm run dev        # 开发预览
npm run build      # 重新构建产物
npm run data:validate   # 数据质量校验
```

## 技术栈

Vue 3 · Vite 6 · TypeScript · Apache ECharts 5 · Vue Router 4 · 汇文明朝体（本地子集化）
